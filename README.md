### 🚀 Featured Engineering Projects

#### 1. [DS Repricer](https://dsrepricer.com) — Multi-Marketplace E-Commerce Automation Platform
*A multi-tenant supplier-to-eBay automation and repricing platform operating across AU, US, UK, DE, and CA.*
- **Architecture:** Monorepo (Turborepo), Next.js, Fastify (OpenAPI + Zod), PostgreSQL 16 + Drizzle Forced Row-Level Security (RLS), BullMQ/Redis workers.
- **Engineering Highlights:** Automated 2-hour price/stock monitoring, dynamic category fee engine, regional delivery verification, and defense-in-depth security (TOTP MFA, strict CSP, audit logging).
- **Reliability:** Built with over **4,500+ unit, integration, and Playwright E2E tests**.

#### 2. [Global eBay Fee & Profit Calculator](https://ebayfeescalc.com)
*Real-time multi-currency calculator engine built for cross-border e-commerce sellers across 19 global marketplaces.*
- **Tech Stack:** Next.js (App Router), TypeScript (Strict), Tailwind CSS, Supabase / PostgreSQL, Drizzle ORM, Vercel.
- **Engineering Highlights:** Complex localized fee calculations, sub-second Core Web Vitals, Schema.org JSON-LD structured data, and `llms.txt` endpoints for AI discovery.
- **Testing:** 1,050+ Vitest unit tests & E2E verification suites.

#### 3. Smart Traffic Simulation & Autonomous Vehicle Runtime (BS Final Year Project)
*Real-time 3D traffic simulation and autonomous vehicle navigation system.*
- **Tech Stack:** Unity 3D, C#, Realistic Car Controller (RCC V4).
- **Engineering Highlights:** Dynamic traffic routing, physical sensor simulation, collision avoidance systems, and comprehensive Agile engineering documentation (SRS, DFD, Architecture Containers).
